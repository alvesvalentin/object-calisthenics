# Object Calisthenics Katas 🏋️‍♂️

Welcome to this repository dedicated to practicing different coding katas while applying **Object Calisthenics** rules. This is a training ground for improving your object-oriented design skills through deliberate practice.

## 📚 What is Object Calisthenics?

Object Calisthenics is a set of 9 programming rules proposed by Jeff Bay to encourage better object-oriented code. These rules help you write cleaner, more maintainable, and more modular code.

The 9 rules are:

1. **Only One Level of Indentation Per Method**
2. **Don’t Use the ELSE Keyword**
3. **Wrap All Primitives and Strings**
4. **First Class Collections**
5. **One Dot per Line**
6. **Don’t Abbreviate**
7. **Keep All Entities Small**
8. **No Classes with More Than Two Instance Variables**
9. **No Getters/Setters/Properties**

Read more about Object Calisthenics [here](https://williamdurand.fr/2013/06/03/object-calisthenics/).

## 🎯 Purpose

This repo is meant for:

- Practicing coding katas to improve problem-solving skills
- Applying Object Calisthenics rules to strengthen OOP design habits
- Experimenting with different approaches while keeping code clean and modular

## 🏗️ Structure

Each kata is located in its own folder:

```
./katas/
  ├── kata-name-1/
  ├── kata-name-2/
  └── ...
```

Inside each folder, you will find:

- `README.md`: Explanation of the kata
- `src/`: Source code
- `tests/`: Unit tests

## 🚀 Getting Started

1. **Clone the repository**

```bash
git clone https://github.com/your-username/object-calisthenics-katas.git
cd object-calisthenics-katas
```

2. **Pick a kata**

Choose a kata from the `katas/` folder and read its `README.md`.

3. **Start coding**

Implement the solution while following the Object Calisthenics rules!
